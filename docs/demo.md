# Recording a demo

About three minutes. Start the launcher on a small git project with `--worktrees`, join the Haunted Office world.

| Time | Shot | Say |
|---|---|---|
| 0:00 | Office from the door, ghosts idle. | "Every Kiro agent is a ghost." |
| 0:15 | **K → + New ghost**, summon *Coder*. | Instant summon, model picker. |
| 0:35 | Chat: ask for a change; approval card appears; Allow. | Agents ask before touching files. |
| 0:55 | Wall: Live code shows the diff as it is written. | Edits on the wall in real time. |
| 1:15 | **Workflows → Lead delegates**, run a task. | Lead plans, Coder codes, Tester and Reviewer run in parallel. |
| 1:50 | `@Reviewer message` in `# crew` while running. | Mid-turn steering. |
| 2:05 | **K → Merges**: diff, then **Merge**. | Nothing lands without your approval. |
| 2:25 | Sneak + right-click a wall: the browser, type a search. | Headless Chrome streamed into the game. |
| 2:45 | Close on the office with the dashboard wall. | "Haunted Crew." |

Tips: use a 1920×1080 window, hide the debug screen, and keep the task small so the run finishes in under a minute.
