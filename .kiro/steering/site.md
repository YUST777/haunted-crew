# Working on the website

Live at https://haunted-crew.pages.dev (Cloudflare Pages project `haunted-crew`, deployed by hand with wrangler).

## Structure

- File routes in `src/routes/`: `index.tsx` (landing page), `docs.index.tsx` and `docs.$page.tsx` (docs).
  `routeTree.gen.ts` is generated by the TanStack Router Vite plugin; do not edit it.
- Landing page sections are components in `src/components/`: `Hero`, `CrewSection`, `FeaturesSection`, `Footer`.
  Add a new section as its own component and place it in `routes/index.tsx`.
- The docs pages render `../../docs/*.md` at build time. Edit the markdown in `/docs`, never a copy in the site.
- "Copy install prompt" copies the fenced text block from `INSTALL_PROMPT.md`. Change the prompt there.
- `public/llms.txt` and `llms-full.txt` summarise the project for AI readers. Update them when the docs change shape.

## Look

- Dark haunted office: background `#0b1016`, green accent `#36e07c`, cyan glow `#3dffe2`.
- Headings use Pixelify Sans 700; body text Poppins; code and the setup terminal JetBrains Mono. Fonts are
  self-hosted through `@fontsource`, no Google Fonts requests.
- Ghost art is 2D sprites (`public/assets/*.webp`) animated with CSS. Do not add three.js to the hero; a 3D
  section must lazy-load its own chunk so the first paint stays small.
- Every animation stops under `prefers-reduced-motion: reduce`.

## Checks before you say a change is done

1. `npm run typecheck` (the `site-typecheck-on-save` hook runs it on every save) and `npm run build`.
2. Look at it: screenshot at 1440x900 and 390x844 and check there is no horizontal scroll on mobile.
3. Keep images small: webp, sized to how big they are drawn. Anything over 1 MB needs a reason.
